Карта проектных лидеров Челябинской области

Загрузите содержимое архива в папку сайта на сервере, сохранив структуру:
index.html, app.js, styles.css, assets/, data/.
Можно размещать как в корне домена, так и в отдельной подпапке.
Node.js, сборка и база данных на сервере не нужны. Сайт работает через HTTP/HTTPS.
Для обновления данных замените data/chelyabinsk_leaders_map.json.
Для локального просмотра: python -m http.server 8000, затем http://localhost:8000.

Основа — последняя согласованная пермская версия с сохранением прокрутки.
Данные — только приложенный data.xlsx. Excel в публичный архив не включён.
